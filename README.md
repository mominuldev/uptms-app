# UPTMS — public website

Next.js 16 site for **University Place TMS Clinic & General Psychiatry**, rendered from the Laravel API in [`../uptms-ad`](../uptms-ad).

- Design: [Figma · Version C](https://www.figma.com/design/ij7CwMEI0miNBTQn0lF0AE/UPTMS?node-id=25-2)

```sh
cp .env.example .env.local
npm install
npm run dev      # http://localhost:3000
```
